Reading the Nose

An explanation that passes a faithfulness test can still be meaningless. Across 750 held-out molecules, 36% of attention maps both predicted their own model's behaviour and reproduced almost exactly on a model whose weights had been thrown away. The faithfulness score never flagged one of them.

What a spurious explanation looks like

Left is the attention map from a model trained to 0.86 macro AUROC. Middle is the same architecture with every weight reinitialised — it has learned nothing at all. They are the same picture. Right is integrated gradients on the trained model, which moves when the weights move.

selected molecule

Attention here is not degenerate or flat — it is varied, confident, and chemically plausible-looking. That is exactly what makes it dangerous. The only thing separating it from a real explanation is a check that most published attention figures never run.

03 — Does the architecture earn itself

Graph structure matters. Attention barely registers.

Odour-descriptor prediction over 4,975 molecules, scaffold-disjoint split, 3 folds × 3 seeds. Graph structure buys a large, reliable gain over a flat fingerprint. Adding attention on top buys almost nothing.

Not a competitive result. OpenPOM's own ensemble is stronger and the task is theirs. The claim is the internal comparison, measured under identical conditions — not a better odour predictor.

05 — Case study

The small-sample stress test

Labelled aside This half was run first, on 13 molecules, as the harder and more novel test. It failed cleanly: no model beat a constant prediction. The odour task above was added afterwards to find out whether that meant the method was wrong or the data was too thin. It was the data. This section is kept because the failure is informative, not because it worked.

What did survive is the sensor's confusion geometry. Amber is how similar two molecules look to the sensor array. Cyan is how similar they are chemically. Where amber runs long and cyan runs short, a £3 sensor is confusing molecules with nothing in common.

06 — Limits

What this does not show

One architecture

A single GATv2 configuration, untuned, carried over unchanged so the two tasks stay comparable. A different head count or a tuned model might behave differently. Not tested.

"Not detected", not "absent"

Attention adds +0.0046 macro AUROC over a plain GCN. Three folds cannot resolve an effect that small. The supported claim is that attention's contribution is far below graph structure's, not that it is exactly zero.

A retracted finding

An earlier version of this work reported attention as perfectly uniform. That was an aggregation bug: summing a softmax over its own normalising axis. It was caught by an independent check, retracted, and documented rather than quietly deleted.

Thirteen molecules

The sensor half covers every public metal-oxide array dataset with identified single-molecule analytes. Median size three heavy atoms. In the largest of them, analyte identity is fully confounded with concentration.
